# Ad Campaign Performance Analyzer mockups

These assets document the planned interface before implementation. All values shown are illustrative sample data rather than final analytical results.

## Interactive mockup

- [Open the interactive dashboard mockup](./ad-campaign-dashboard-mockup.html)

The interactive version demonstrates the dashboard navigation, sample-versus-upload data selection, global filters, campaign search, and time-series metric controls.

## Recreating the images

Run the following command from the repository root:

```bash
node Week1/docs/mockups/capture_mockups.cjs
```

The capture script requires Playwright and a local Google Chrome installation.
